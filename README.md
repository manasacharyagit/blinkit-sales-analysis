# Blinkit Sales Analysis

An end-to-end analysis of Blinkit order data using SQL (MotherDuck) and Tableau.

## Tools Used
- MotherDuck (SQL)
- Tableau (dashboard)

## Dashboard
[View the dashboard presentation](blinkit.pptx)

## SQL Queries
[View all SQL queries](blinkit_queries.sql)

## Questions Answered
- Executive KPIs: total customers, total orders, total revenue, average order value
- Sales and revenue by product category
- Most used payment methods
- Times of day when orders are most frequent
- Top 10 brands
- Delivery distance analysis
- Marketing channel performance

## Key Insights
- Top revenue category: Dairy & Breakfast
- Brand having the highest profit margin: Jha Group
- Most used payment method: Card
